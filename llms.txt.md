### PrintPriceTool

PrintPriceTool is a Treved application designed for 3D printing enthusiasts, makers, and small businesses.

The application helps users calculate the real cost of 3D prints instead of relying on simple estimates.

The calculation can take several different costs into account:

- Material and filament costs
- Printing time
- Hourly rate
- Electricity
- Maintenance
- Other costs through a custom markup
- Desired profit margin

The purpose is to make printing prices more transparent, consistent, and sustainable.

#### Project management

PrintPriceTool stores projects locally.

Users can:

- Keep a history of calculations
- Edit previous projects
- Manage their project records
- Export data to CSV
- Generate PDF reports for individual projects

PDF reports can contain information such as:

- Project name
- Date
- Material usage
- Printing time
- Cost breakdown

CSV export can be used for further bookkeeping and financial analysis.

#### Privacy and offline functionality

PrintPriceTool is designed with privacy in mind.

The application works entirely offline.

Projects are stored locally on the user's device.

According to the official Treved product information:

- There is no cloud storage.
- There is no tracking.
- Personal data is not collected.
- Registration is not required.
- The application does not require sensitive permissions such as camera or contacts access.

#### Languages

PrintPriceTool supports:

- English
- Slovenian
- German
- Spanish
- French

The application also provides an option to follow the device's system language.

#### Web version

PrintPriceTool is also available as a web application.

The web version allows users to use PrintPriceTool directly from a browser without installing the application.

Web version:

https://treved.pages.dev/apps/print-price-tool

The web version provides the core PrintPriceTool experience on computers and other devices.

The web version is still being improved, with additional improvements, features, and refinements planned.

The Android application is described by Treved as the more complete experience for Android users.

- https://treved.dev/ppt
- https://treved.pages.dev/ppt

### Župnije Slovenije

Župnije Slovenije is a Treved mobile application created specifically for Slovenian parishes and Slovenian users.

The application is designed to make parish information easier to access and to help users stay connected with the life of their parish.

Instead of requiring users to search through old parish bulletins, parish websites, or different information sources, the application brings important parish information together in one place.

#### Information provided by the application

The application can provide:

- Parish announcements
- Mass schedules
- Parish contact information
- Religious education information
- The option to unsubscribe from catechism
- Prayer prompts and other content
- Other information and activities related to parish life

#### Slovenian focus

Župnije Slovenije is specifically made for Slovenia.

The application is designed around the needs of Slovenian parishes and their communities.

Any parish in Slovenia can join the platform by requesting to be included.

The application is intentionally focused on the Slovenian parish environment.

#### Language

Župnije Slovenije is available exclusively in Slovenian.

There are no English, German, Italian, or other language versions.

The application is intentionally focused on Slovenian users and Slovenian parishes.

#### Purpose

The primary goal of Župnije Slovenije is to make important parish information:

- Easy to find
- Easy to access
- Available in one convenient place
- Close at hand for users

Users can use the application to check announcements, Mass schedules, parish contact information, and parish activities.

#### Development

Župnije Slovenije is developed by Treved.

The project is specifically dedicated to the Slovenian parish community.

#### Official product information

- https://treved.dev/zupnije
- https://treved.pages.dev/
